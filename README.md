# Telegram Moderator Bot 🤖

Умный Telegram-бот на Python для автоматической модерации контента, фильтрации спама и управления сообществом в реальном времени.

## 🚀 Основной функционал
* **Фильтрация спама:** Автоматическое удаление нежелательных ссылок и стоп-слов.
* **База знаний:** Использование локального текстового хранилища для сверки правил модерации.
* **Логирование:** Интеграция с базой данных SQLite для учета действий пользователей и истории предупреждений.
* **Безопасность:** Вынос токена бота и конфигурации в изолированные переменные окружения (`.env`).

## 🛠 Стек технологий
* **Language:** Python 3.x
* **Framework:** pyTelegramBotAPI (telebot)
* **Database:** SQLite
* **Environment:** python-dotenv

## 📦 Инструкция по локальному запуску

1. Клонируйте репозиторий:
  git clone https://github.com/Faller567/telegram-moderator-bot.git

2. Установите необходимые зависимости:
   pip install -r requirements.txt

3. Создайте файл .env в корневой директории проекта и добавьте ваш токен:
   BOT_TOKEN=ваш_токен_от_BotFather

4. Запустите бота:
  python main.ru.py
